# C：局部参考／时序残差原型

本实现仅新增 `teeth_local/model_c.py` 中的 `TemporalResidualC(torch.nn.Module)`，供后续公共训练器调用。不修改 v1 推理、背景、`__init__.py`，不复制训练器。只依赖现有 torch；没有训练、权重下载或效果验证，也不发布 v1.1。

## 接口与输入契约

`TemporalResidualC().forward(base, reference, allowed) -> residual`

| 张量 | 形状 | 约束 |
| --- | --- | --- |
| `base` | `B,T,3,H,W` | 固定 A/v1 底片序列，非空，浮点、有限值且在 `[0,1]` |
| `reference` | `B,3,H,W` | 每个样本对应的固定 A 基准首帧，范围和浮点类型同 base |
| `allowed` | `B,T,1,H,W` | bool，安全可编辑状态，不是真实牙齿几何真值 |
| `residual` | `B,T,3,H,W` | tanh 有界 RGB 残差，范围 `[-1,1]`，不是合成图像 |

三个输入与全部模型参数必须在同一设备；base/reference 与模型参数必须具有相同浮点类型。模块对类型、形状、设备和输入数值范围进行检查，违规时抛出明确的 TypeError/ValueError。输出不做加法合成、裁剪或区域保护。

**参考绝不能使用 GT**：训练器应从固定 A 基准输出中选取首帧，且与当前样本对应。即使训练片段从中间开始，也不能把相应 GT 帧或后续真实帧当成参考。模块无法从张量数值鉴定来源，必须由公共数据管线记录 A 版本、样本及参考帧来源并阻止泄漏。GT 如获准使用，只能通过独立监督路径进入损失，不能进入此 forward。

## 结构与时序语义

- base 各帧和 reference 共用同一个两层 3×3 卷积编码器，特征宽度均为 24；拼接后作为 ConvGRU 条件，隐藏状态宽度也是 24。
- 参考特征每次 forward 编码一次；状态以零初始化并仅存在于当前调用的局部变量中。不同 batch 样本独立，不跨调用缓存状态。
- 对每个样本、每帧单独判断 allowed 是否全空：全空时通过 `torch.where` 保留前状态，非空时按 ConvGRU 更新。候选计算仍会执行，但全空样本不采用该候选状态。非空时更新整张特征图，不把 mask 当作空间牙列监督。
- RGB 输出卷积的权重、偏置均零初始化，因此新建模型在有效输入下初始残差为零。训练后空 mask 帧仍可能读出旧状态对应的非零残差；**保留状态不等于残差归零，也不等于保护已经完成**。
- 每次调用重置状态，所以分段调用不等价于一次连续调用；公共训练器需要明确序列窗口边界。本类没有外部状态或跨窗口状态接口。

## 数据、安全边界与局限

allowed 依赖审核过的可见区域及保护规则。存在不确定、闭口或遮挡时，是否设为空应由数据准入规则决定；本类不检测牙齿，也不能验证 mask 是否真实可靠。非空误标会推进状态；全空策略也不能凭空恢复被遮挡的牙齿结构。

B 分支公共训练器必须使用固定 v1 底片，只在允许的下牙及必要口腔内部边界内合成修正，并保护上牙、嘴唇和所有区外像素；模块返回的全图残差不能直接加到整帧后作为交付。合成前无损帧的允许区外最大像素差必须为 0，最终 MP4 编码差异单独记录。禁止仅凭隐藏状态门控或参数冻结宣称背景保持不变。

本类是局部参考／时序原型，不是显式 3D 牙列、牙齿身份模型或几何重建器，不保证任意遮挡后的结构稳定。细牙缝标注仍有可靠性限制；真实数据、可见 mask、素材来源关系和训练用途必须按公共门槛准入，不能以原型代码替代审核。
